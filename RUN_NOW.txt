INTERVIEWIQ — QUICK RUN (PYTHON 3.14)

1) Open PowerShell in this project folder.

2) Create the virtual environment:
   py -3.14 -m venv .venv

3) Activate it:
   .\.venv\Scripts\Activate.ps1

   If PowerShell blocks activation, skip activation and use:
   .\.venv\Scripts\python.exe

4) Install dependencies:
   python -m pip install --upgrade pip
   python -m pip install -r requirements.txt

5) The trained model is already included.
   You do NOT need to train again just to run the website.

6) Start the website:
   python -m uvicorn app.main:app --reload

7) Open in your browser:
   http://127.0.0.1:8000

RESULT FORMAT
-------------
The web app shows only:
   Weak
   Average
   Strong

Scores, percentages, confidence, and similarity values are not shown in the UI.

OPTIONAL TRAINING
-----------------
To reproduce the embedding/fusion comparison:
   python train_interviewiq.py

The training script compares:
- TFIDF-SVD
- GloVe-style-SVD
- Word-Distribution-SVD
- Subword-SVD
with Early and Late Fusion followed by an MLP classifier.

DATASET NOTE
------------
The supplied validated dataset contains 985 resolved records after removing
unresolved labels. It contains 20 unique questions and 20 unique answers
repeated across the records. Do not present it as 1000 unique interview
examples or as evidence of generalization to 1000 unique answers.
